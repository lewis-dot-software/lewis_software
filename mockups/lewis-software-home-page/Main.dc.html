# Dan Lewis

I build Dart tools and apps on my own, and hold every one of them to a standard I would want to inherit.

## How I build

My software never watches you. Nothing is gathered, counted or sent anywhere you did not ask for. This site included: it sets no cookies, runs no script and loads nothing from anyone else.

It is tested harder than it strictly needs. Where the tools I wanted for that did not exist, I built them.

## Work

grit

Property-based testing for Dart. You state what should hold for every input, and grit finds one that breaks it, then shrinks it to the smallest case that still fails. The shrinker is checked against a model whose properties are proved in Lean.

await forAll((Draw draw) {
  final xs = draw(.list(.integer()));
  expect(xs.reversed.toList().reversed, xs);
});

muster

Brings the real codebases your Dart and Flutter tools are tested against to the commits and versions you pin, resolved and ready to read. A tool's first dart test needs no setup, and no fetch ever fails silently.
