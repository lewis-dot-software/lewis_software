Work

grit

Property-based testing for Dart.

You state what should hold for every input, and grit finds one that breaks it, then shrinks it to the smallest case that still fails. The shrinker is checked against a model whose properties are proved in Lean.

Dart package · MIT

muster

Real codebases for testing Dart tools.

Brings the codebases your Dart and Flutter tools are tested against to the commits and versions you pin, resolved and ready to read, so a tool's first test run needs no setup and no fetch ever fails silently.

Dart package and CLI · MIT
