lewis.software

I'm Dan Lewis, and I make software on my own.

Mostly Dart: tools first, and apps built on them. I hold all of it to a standard I would want to inherit, and two promises sit under every line.

The first is that it never watches you. Nothing is gathered, counted or sent anywhere you did not ask for. This page keeps it too: no cookies, no script, and nothing loaded from anyone else.

The second is that it is tested harder than it strictly needs. Where the tools for that did not exist, I built them. grit does property-based testing: you say what should hold for every input, and it finds the one that breaks it and shrinks it to the smallest case, with a shrinker checked against a model proved in Lean. muster brings the real codebases a tool is tested against to the commits you pin, so its first test run needs no setup.

If either is useful to you, or broken for you, I'd like to hear. Write to dan@lewis.software, or open an issue on GitHub. The packages live on pub.dev.
